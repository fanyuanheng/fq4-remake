# External game references

These community resources provide gameplay and terminology context for the FQ4
Wrapper. They are linked rather than copied into the repository; their content
and media remain subject to the respective sites' licenses and their original
rights holders.

External guides are useful corroborating material, but they are not treated as
authoritative evidence for save-file offsets or write safety. Binary editor
behavior must still be verified against the supported DOS release and covered
by tests.
